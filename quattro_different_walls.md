# Different Wallpapers per Monitor on Omarchy

Set a different wallpaper on each connected monitor, where the per-monitor
wallpapers **follow the active theme automatically** (switch themes, and each
monitor shows a different background from the new theme).

## How it works

Omarchy renders the desktop wallpaper with the `omarchy.background` shell
service plugin (`/usr/share/omarchy/shell/plugins/background/Background.qml`).
That plugin draws a single global background image — the one pointed to by the
symlink `~/.local/state/omarchy/current/background` — on every monitor.

To get per-monitor wallpapers we:

1. Clone the built-in plugin into user space (`omarchy plugin clone`), which
   replaces `omarchy.background` with `local.background`. **Never edit
   `/usr/share/omarchy/`** — changes are lost on update.
2. Patch the cloned `Background.qml` so each monitor's `PanelWindow` resolves
   its own image from a small config file instead of always using the global
   background.
3. The config entries are resolved **at render time against the active theme's
   backgrounds directory**, and re-resolved on every theme transition, so
   per-monitor wallpapers follow theme changes automatically.

## Files

| File | Role |
|------|------|
| `~/.config/omarchy/backgrounds.json` | Per-monitor wallpaper mapping (config) |
| `~/.config/omarchy/plugins/local.background/Background.qml` | Cloned + patched background service plugin |
| `~/.config/omarchy/plugins/local.background/manifest.json` | Plugin manifest (generated by the clone) |

## Steps to recreate on another Omarchy system

### 1. Clone the background plugin

```bash
omarchy plugin clone omarchy.background
```

This creates `~/.config/omarchy/plugins/local.background/` and automatically
enables `local.background` while disabling the built-in `omarchy.background`.

### 2. Create the config

`~/.config/omarchy/backgrounds.json` — keys are monitor names (from
`hyprctl monitors all`), values select which background each monitor gets:

```json
{
  "eDP-1": 0,
  "HDMI-A-1": 2
}
```

Value formats (per monitor):

| Value | Meaning |
|-------|---------|
| `0`, `2`, … | Index into the **active theme's** backgrounds dir (sorted) |
| `/abs/path/to/img.png` | Absolute path to any image file |
| `filename.png` | Bare filename resolved against the active theme's backgrounds dir |

Monitors not listed (or whose index/file doesn't exist in the current theme)
fall back to the theme's default background.

### 3. Patch the cloned plugin

Replace the stock `~/.config/omarchy/plugins/local.background/Background.qml`
with the file below. The changes from stock are annotated (`// NEW`, `// CHANGED`,
`// FIX`):

- `perMonitorBackgrounds` property + a `Process` that resolves the config
  against the current theme's backgrounds dir (de-duplicated by basename).
- `refreshPerMonitor()` is called from `transitionBackground()` (fires on every
  theme change / background change) and at startup.
- Each `PanelWindow` picks its image via `resolvedBackground` instead of the
  global `displayedBackground`.
- `// FIX`: `revealAnimation.onFinished` + `transitionClearTimer`
  deterministically drop the global reveal overlay after the theme-transition
  animation. The stock cleanup relied on `base` re-emitting `Image.Ready` after
  `finishingTransition` was set — but the per-monitor resolver usually finishes
  mid-reveal, so `base` already reloaded to the new per-monitor image and the
  cleanup never ran, leaving the fully-revealed global snapshot stuck on both
  monitors (the "same wallpaper on both" bug).

Full file (`Background.qml`):

```qml
import Quickshell
import Quickshell.Io
import Quickshell.Wayland
import QtQuick
import QtQuick.Effects
import QtQuick.Shapes
import qs.Commons

Item {
  id: root

  readonly property string home: Quickshell.env("HOME")
  readonly property string stateHome: home + "/.local/state"
  readonly property string currentBackgroundLink: stateHome + "/omarchy/current/background"
  readonly property string perMonitorConfigPath: home + "/.config/omarchy/backgrounds.json"

  property var perMonitorBackgrounds: ({})
  property string currentBackground: ""
  property string displayedBackground: ""
  property string incomingBackground: ""
  property string oldBackground: ""
  property bool finishingTransition: false
  property int backgroundVersion: 0
  property int revealStartedVersion: -1
  property int pendingThemeVersion: -1
  property string pendingColorsRaw: ""
  property string pendingShellRaw: ""
  property real revealProgress: 1

  function imageUrl(path) {
    return Util.fileUrl(path)
  }

  function refreshBackground() {
    if (!readlinkProc.running) readlinkProc.running = true
  }

  // NEW: re-resolve per-monitor entries against the current theme.
  function refreshPerMonitor() {
    if (!perMonitorProc.running) perMonitorProc.running = true
  }

  function setBackground(path, instant) {
    transitionBackground("", path, path, instant, false)
  }

  function transitionBackground(fromPath, path, finalPath, instant, force) {
    path = String(path || "").trim()
    finalPath = String(finalPath || path).trim()
    fromPath = String(fromPath || "").trim()
    if (!path || (!force && finalPath === currentBackground)) return
    currentBackground = finalPath
    backgroundVersion += 1
    revealStartedVersion = -1

    revealAnimation.stop()
    finishingTransition = false

    if (instant || !displayedBackground) {
      oldBackground = ""
      incomingBackground = ""
      displayedBackground = path
      revealProgress = 1
      return
    }

    oldBackground = fromPath || displayedBackground
    incomingBackground = path
    revealProgress = 0
    refreshPerMonitor() // NEW: re-resolve on theme/background change
  }

  function setPendingTheme(colorsB64, shellB64) {
    pendingColorsRaw = Util.decodeBase64(colorsB64)
    pendingShellRaw = Util.decodeBase64(shellB64)
    pendingThemeVersion = backgroundVersion
    pendingThemeFallbackTimer.restart()
  }

  function applyPendingTheme() {
    if (pendingThemeVersion < 0) return
    pendingThemeFallbackTimer.stop()
    Color.loadColors(pendingColorsRaw)
    Color.loadShell(pendingShellRaw)
    Style.scheduleRefresh()
    pendingThemeVersion = -1
    pendingColorsRaw = ""
    pendingShellRaw = ""
  }

  function transitionBackgroundWithTheme(fromPath, path, finalPath, colorsB64, shellB64) {
    transitionBackground(fromPath, path, finalPath, false, true)
    setPendingTheme(colorsB64, shellB64)
    if (!incomingBackground || revealProgress >= 1) applyPendingTheme()
  }

  function startReveal(panel) {
    if (!incomingBackground) return
    panel.maskReady = true
    if (revealStartedVersion === backgroundVersion) return
    revealStartedVersion = backgroundVersion
    applyPendingTheme()
    revealAnimation.restart()
  }

  function openSelector() {
    if (!bgSwitchProc.running) bgSwitchProc.running = true
  }

  function openThemeSwitcher() {
    if (!themeSwitchProc.running) themeSwitchProc.running = true
  }

  Process {
    id: bgSwitchProc
    command: ["bash", "-c", "background=$(omarchy-theme-bg-switcher); [[ -n $background ]] && omarchy-theme-bg-set \"$background\""]
    onExited: root.refreshBackground()
  }

  Process {
    id: themeSwitchProc
    command: ["bash", "-c", "theme=$(omarchy-theme-switcher); [[ -n $theme ]] && omarchy-theme-set \"$theme\" >/dev/null 2>&1 &"]
    onExited: root.refreshBackground()
  }

  Process {
    id: readlinkProc
    command: ["readlink", "-f", root.currentBackgroundLink]
    stdout: StdioCollector {
      onStreamFinished: root.setBackground(String(text || "").trim(), false)
    }
  }

  // NEW: resolve backgrounds.json against the active theme's backgrounds dir.
  // Output is one `monitor<TAB>absolute-path` line per entry, or nothing when
  // the entry can't be satisfied (caller falls back to the theme default).
  //
  // The resolver de-duplicates by basename (e.g. "0-sakura-mochi.png" +
  // "0-sakura-mochi.jpg" count as ONE entry; the last one in sort order wins).
  // Omarchy's theme-switch flow can drop a converted copy next to the original
  // image, and without this de-dupe those extra files silently shift every
  // index and give monitors the wrong wallpaper.
  Process {
    id: perMonitorProc
    command: ["bash", "-c", "cfg=\"$HOME/.config/omarchy/backgrounds.json\"; [[ -f \"$cfg\" ]] || exit 0; theme_dir=\"$HOME/.local/state/omarchy/current/theme/backgrounds\"; raw=(); if [[ -d \"$theme_dir\" ]]; then while IFS= read -r -d '' f; do raw+=(\"$f\"); done < <(find -L \"$theme_dir\" -maxdepth 1 -type f \\( -iname '*.jpg' -o -iname '*.jpeg' -o -iname '*.png' -o -iname '*.gif' -o -iname '*.bmp' -o -iname '*.webp' \\) -print0 | sort -z); fi; declare -A seen; for f in \"${raw[@]}\"; do base=${f##*/}; key=${base%.*}; seen[$key]=$f; done; files=(); while IFS= read -r key; do [[ -n \"$key\" ]] && files+=(\"${seen[$key]}\"); done < <(printf '%s\\n' \"${!seen[@]}\" | sort); jq -r 'to_entries[] | [.key, (.value | tostring)] | @tsv' \"$cfg\" 2>/dev/null | while IFS=$'\\t' read -r mon spec; do resolved=\"\"; if [[ \"$spec\" =~ ^[0-9]+$ ]]; then i=$((10#$spec)); (( i >= 0 && i < ${#files[@]} )) && resolved=\"${files[$i]}\"; elif [[ \"$spec\" == /* ]]; then [[ -f \"$spec\" ]] && resolved=\"$spec\"; else [[ -f \"$theme_dir/$spec\" ]] && resolved=\"$theme_dir/$spec\"; fi; [[ -n \"$resolved\" ]] && printf '%s\\t%s\\n' \"$mon\" \"$resolved\"; done"]
    stdout: StdioCollector {
      onStreamFinished: {
        var map = {}
        var lines = String(text || "").split("\n")
        for (var i = 0; i < lines.length; i++) {
          var line = lines[i].trim()
          if (!line) continue
          var tab = line.indexOf("\t")
          if (tab <= 0) continue
          var mon = line.slice(0, tab)
          var path = line.slice(tab + 1)
          if (mon && path) map[mon] = path
        }
        root.perMonitorBackgrounds = map
      }
    }
  }

  IpcHandler {
    target: "background"

    function refresh(): void {
      root.refreshBackground()
    }

    function set(path: string): void {
      root.setBackground(path, false)
    }

    function setInstant(path: string): void {
      root.setBackground(path, true)
    }

    function transition(fromPath: string, path: string): void {
      root.transitionBackground(fromPath, path, path, false, false)
    }

    function themeTransition(fromPath: string, path: string, finalPath: string, colorsB64: string, shellB64: string): void {
      root.transitionBackgroundWithTheme(fromPath, path, finalPath, colorsB64, shellB64)
    }
  }

  Timer {
    id: pendingThemeFallbackTimer
    interval: 300
    repeat: false
    onTriggered: root.applyPendingTheme()
  }

  NumberAnimation {
    id: revealAnimation
    target: root
    property: "revealProgress"
    from: 0
    to: 1
    duration: 420
    easing.type: Easing.InOutCubic
    onFinished: {
      if (root.incomingBackground) {
        root.displayedBackground = root.currentBackground || root.incomingBackground
        root.finishingTransition = true
      }
      root.revealProgress = 1
      // FIX: drop the reveal layers once the animation completes. The
      // per-monitor resolver usually finishes mid-reveal, so base has already
      // re-emitted Image.Ready by now and the old onStatusChanged cleanup
      // would never run again — leaving the global incoming snapshot stuck on
      // every monitor (same wallpaper everywhere). A short grace period lets
      // base finish loading the final per-monitor image to avoid a blank flash.
      transitionClearTimer.restart()
    }
  }

  // FIX: deterministic cleanup of the reveal overlay. Without this, changing
  // the theme left the fully-revealed global snapshot on top of the per-monitor
  // base image forever, so both monitors showed the same wallpaper.
  Timer {
    id: transitionClearTimer
    interval: 200
    repeat: false
    onTriggered: {
      root.incomingBackground = ""
      root.oldBackground = ""
      root.finishingTransition = false
      root.refreshPerMonitor()
    }
  }

  Component.onCompleted: {
    refreshBackground()
    refreshPerMonitor() // NEW: initial resolution
  }

  Variants {
    model: Quickshell.screens

    PanelWindow {
      id: panel
      required property var modelData

      screen: modelData
      visible: true
      anchors { top: true; bottom: true; left: true; right: true }
      color: "transparent"
      updatesEnabled: true

      property bool maskReady: false

      // NEW: this monitor's wallpaper (absolute path) or "" to use theme default.
      readonly property string panelBackground: String(root.perMonitorBackgrounds[modelData.name] || "")
      readonly property string resolvedBackground: panelBackground || root.displayedBackground

      function maybeStartReveal() {
        if (!root.incomingBackground || root.revealProgress !== 0 || maskReady) return
        if (incomingFrame.status !== Image.Ready) return
        Qt.callLater(function() {
          if (!root.incomingBackground || root.revealProgress !== 0 || maskReady) return
          if (incomingFrame.status !== Image.Ready) return
          root.startReveal(panel)
        })
      }

      WlrLayershell.namespace: "omarchy-background"
      WlrLayershell.layer: WlrLayer.Background
      WlrLayershell.keyboardFocus: WlrKeyboardFocus.None
      exclusionMode: ExclusionMode.Ignore

      Image {
        id: base
        anchors.fill: parent
        source: root.imageUrl(panel.resolvedBackground) // CHANGED: per-monitor image
        fillMode: Image.PreserveAspectCrop
        asynchronous: true
        cache: true
        onStatusChanged: {
          if (status === Image.Ready && root.finishingTransition) {
            root.incomingBackground = ""
            root.oldBackground = ""
            root.finishingTransition = false
          }
        }
      }

      Image {
        id: oldFrame
        anchors.fill: parent
        source: root.imageUrl(root.oldBackground)
        fillMode: Image.PreserveAspectCrop
        asynchronous: true
        cache: false
        smooth: true
        mipmap: true
        visible: root.oldBackground !== "" && root.revealProgress < 1
        onStatusChanged: panel.maybeStartReveal()
      }

      Item {
        id: incomingLayer
        anchors.fill: parent
        visible: root.incomingBackground !== "" && incomingFrame.status === Image.Ready && (root.revealProgress >= 1 || panel.maskReady)
        layer.enabled: root.incomingBackground !== "" && root.revealProgress < 1
        layer.smooth: true
        layer.effect: MultiEffect {
          maskEnabled: true
          maskSource: revealMask
          maskThresholdMin: 0.5
          maskSpreadAtMin: 0.02
        }

        Image {
          id: incomingFrame
          anchors.fill: parent
          source: root.imageUrl(root.incomingBackground)
          fillMode: Image.PreserveAspectCrop
          asynchronous: true
          cache: false
          smooth: true
          mipmap: true
          onStatusChanged: panel.maybeStartReveal()
        }
      }

      Item {
        id: revealMask
        anchors.fill: parent
        visible: false
        layer.enabled: true

        readonly property real slant: -0.18
        readonly property real centerTop: width / 2 - slant * height / 2
        readonly property real centerBottom: width / 2 + slant * height / 2
        readonly property real reach: width / 2 + Math.abs(slant) * height / 2 + 4
        readonly property real spread: reach * root.revealProgress

        Shape {
          anchors.fill: parent
          antialiasing: true
          preferredRendererType: Shape.CurveRenderer
          ShapePath {
            fillColor: "white"
            strokeColor: "transparent"
            startX: revealMask.centerTop - revealMask.spread; startY: 0
            PathLine { x: revealMask.centerTop + revealMask.spread; y: 0 }
            PathLine { x: revealMask.centerBottom + revealMask.spread; y: revealMask.height }
            PathLine { x: revealMask.centerBottom - revealMask.spread; y: revealMask.height }
            PathLine { x: revealMask.centerTop - revealMask.spread; y: 0 }
          }
        }
      }

      Connections {
        target: root
        function onIncomingBackgroundChanged() {
          panel.maskReady = false
          panel.maybeStartReveal()
        }
      }

      MouseArea {
        anchors.fill: parent
        acceptedButtons: Qt.LeftButton | Qt.RightButton
        onDoubleClicked: function(mouse) {
          if (mouse.button === Qt.RightButton) root.openThemeSwitcher()
          else root.openSelector()
          mouse.accepted = true
        }
      }
    }
  }
}
```

> `oldFrame` and `incomingFrame` intentionally keep using the global
> `root.oldBackground` / `root.incomingBackground`. Those paths are the theme
> transition *snapshots* (which always exist), whereas a per-monitor path can
> briefly point into a theme directory that a theme switch just deleted. This
> keeps the reveal animation safe; the steady-state `base` image is what shows
> the per-monitor wallpaper.

### 4. Apply

```bash
omarchy restart shell
```

**IMPORTANT:** `omarchy-shell shell rescanPlugins` only rescans the plugin
catalog/manifests. It does **not** reload QML source of a running service
plugin. After any edit to `Background.qml` or `backgrounds.json`, restart the
shell:

```bash
omarchy restart shell
```

### 5. Verify

```bash
# Both monitors should list an omarchy-background layer
hyprctl layers

# Sanity-check the resolution logic (prints resolved paths per monitor)
omarchy-shell -q background refresh
```

## Behaviour notes

- **Theme changes follow automatically**: `omarchy theme set <theme>` swaps the
  active theme's backgrounds dir and fires `background themeTransition` IPC,
  which re-runs the resolver. `eDP-1: 0` / `HDMI-A-1: 2` pick different images
  from whatever theme is active.
- **Fallback**: if the current theme doesn't have that many backgrounds (e.g.
  a theme with only 2 backgrounds and a config index of `2`), the monitor falls
  back to the theme's default background instead of showing a broken image.
- **Monitors without an entry** always use the theme default.
- `omarchy theme bg next` keeps per-monitor pins (they re-resolve against the
  same theme dir, unchanged).
- Restarting the shell is required after edits because `rescanPlugins` does not
  reload service QML.

## Example resolution

With `~/.config/omarchy/backgrounds.json` = `{ "eDP-1": 0, "HDMI-A-1": 2 }`:

| nord | `0-black-moon.jpg` | `2-night-hawks.png` |
| catppuccin | `1-totoro.png` | `3-blue-eye.png` |
| everforest (only 2 bgs) | `1-tree-tops.jpg` | *(fallback → theme default)* |

## Troubleshooting

- **Same wallpaper on both monitors after a theme change.** The resolver and
  map are almost certainly fine (check `~/.local/state/omarchy/current/theme/backgrounds`
  and that `backgrounds.json` exists). With the `// FIX` code in place, the
  reveal overlay is cleared automatically 200 ms after the transition animation
  completes, so this should not happen. If you still see it, you are running an
  older `Background.qml` without `transitionClearTimer` — re-copy the file from
  this doc, then:

  ```bash
  omarchy restart shell
  ```

- **A monitor picked the theme's logo file (`omarchy.png`).** Themes vary wildly
  in their backgrounds dirs. A theme with only a few files — e.g. lumon with
  `01-united-in-severance.jpg`, `02-opinions-equally.jpg`, `omarchy.png` —
  resolves index `2` to `omarchy.png`. The index is counted over the whole
  sorted dir, including non-wallpaper files. To force a real image, use an
  absolute path or filename in the config instead of an index:

  ```json
  { "eDP-1": 0, "HDMI-A-1": "02-opinions-equally.jpg" }
  ```

- **Monitors got each other's (or the wrong index) wallpaper after a theme
  switch.** Omarchy's theme-set flow can create a converted copy such as
  `0-sakura-mochi.jpg` beside the original `0-sakura-mochi.png`. A plain sorted
  listing then counts both, shifting every index. The resolver in this doc
  de-duplicates by basename, so this should not happen — if it does, you have
  an older resolver (without the `declare -A seen` de-dupe) and should re-copy
  the `perMonitorProc` from this file.

- **Editing Background.qml / backgrounds.json has no effect.** `omarchy-shell
  shell rescanPlugins` only rescans the plugin catalog — it does **not** reload
  QML source of a running service plugin. Always:

  ```bash
  omarchy restart shell
  ```

- **Config sanity check (what the resolver sees):**

  ```bash
  # current theme's backgrounds dir
  ls ~/.local/state/omarchy/current/theme/backgrounds/
  # is the config present?
  cat ~/.config/omarchy/backgrounds.json
  ```
